# Neon React Clock

첨부 이미지를 참고해 만든 반응형 네온 아날로그 시계입니다. 브라우저의 현재 시각에 맞춰 시침·분침·초침이 부드럽게 움직입니다.

## 🔗 라이브 데모 (배포 주소)

👉 [여기에서 시계를 직접 확인해 보세요!](https://github.io)

## 🛠️ 사용 기술 (Tech Stack)

- React
- Vite
- CSS3 (Neon Glow Effects)

## 🏃‍♂️ 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
npm run preview
```

## 🚀 배포 방법 (Deploy)

GitHub Pages에 프로젝트를 배포하려면 아래 명령어를 입력합니다.

```bash
npm run deploy
```
